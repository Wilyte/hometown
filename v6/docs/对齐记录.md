# v6 对齐记录（three.js → Godot）

## 1. 先把页面侧的真值挖出来

`viewer.js`（`/viewer.js?v=...`）里的观看器配置：

```
new THREE.WebGLRenderer({ canvas, antialias: true, alpha: dark })
renderer.shadowMap.enabled = true; type = PCFSoftShadowMap
scene.background = new THREE.Color(opts.bg)          // 本页 opts.bg = 0xeaf1fe
camera = new THREE.PerspectiveCamera(38, 1, 0.01, 200)
hemi  = new THREE.HemisphereLight(0xffffff, 0xb8b0a4, 1.15)
key   = new THREE.DirectionalLight(0xfff2e0, 2.4)  key.position.set(4, 7, 5)
rim   = new THREE.DirectionalLight(0xdfe8ff, 0.9)  rim.position.set(-5, 4, -6)

camera.near = max(0.01, sphere.radius * 0.012)
camera.far  = max(200, sphere.radius * 30)
d    = sphere.radius / sin(fov/2) * (opts.fit || 1.12)   // 本页 fit = 0.525
pitch= 17.8°; yaw = 0.61
```

页面 `mountViewer(...)` 的调用参数：`{ idle: true, nightLights: true, bg: 0xeaf1fe,
looksUrl: '/looks.mjs', fit: 0.525, pitch: 17.8, frameRight: null, smoke: [], spin: [] }`。

运行时用 `window.__kitViewer.view()` 直接读到的相机：

```
position (58.8455, 34.8752, 84.8829)  target (-1.9787, 0.7862, -2.1432)  fov 38
```

本工程算出来的：`center = (-1.97868, 0.78618, -2.143234)`、`radius = 69.153`、
`d = 111.513`、`pitch = 17.8°`、`yaw = 0.610` —— 与页面逐位对得上。

> 半径按 `Box3.getBoundingSphere` 的定义取 **AABB 半对角线**（不是最远顶点），
> 所以 Godot 侧也照这个口径算，才能得到同一个 d。

## 2. 光照归一化标定（`tools/calib.gd`）

一张 albedo=0.5 的白板正对光源，线性域读数：

| 用例 | 线性输出 | 结论 |
|---|---|---|
| 背景 `gray 0.5` | 0.2122 | `background_color` 走 sRGB→线性 |
| 平行光 白 / E=0.25 | 0.2502 | Godot 平行光系数 **k=1**（three.js 是 1/π=0.3183） |
| 平行光 `gray 0.5` / E=0.25 | 0.0529 | `light_color` 也走 sRGB→线性 |
| 环境色 `gray 0.5` / E=1 | 0.2122 | 环境色同样 sRGB→线性 |
| albedo `gray 0.5` / E=1 | 0.2122 | `albedo_color` 同样 sRGB→线性 |
| 天光纯白 `radiance_scale=1` | 1.0000 | 天光辐照度系数 1.0，颜色直接当辐照度 |

据此：three.js 的 `intensity` 一律 `/π` 变成 Godot 的 `light_energy`；半球光的
`intensity/π` 变成天光贴图的 `radiance_scale`；所有颜色按 sRGB 原样给。

## 3. 顶点色

`tools/inspect_glb.py`：533 mesh / 162,233 tris，属性全带 `COLOR_0`，材质
`metallicFactor 0`、`roughnessFactor 0.85~0.96`、无贴图。导入后 `tools/probe_glb.gd`
实测 `536/536` 个 `StandardMaterial3D` 的 `vertex_color_use_as_albedo = false`，
于是整片白。`main.gd::_enable_vertex_colors()` 对 183 个共享材质各打开一次即可。

## 4. 背景

页面 body 是 `class="asset landing"` → viewer 走 `alpha: dark` 分支，canvas 透明、
`scene.background = null`；看到的底色其实是 canvas 元素自己的 CSS：

```
radial-gradient(120% 130% at 32% 18%, rgb(255,255,255) 0%, rgb(238,242,247) 55%, rgb(223,230,239) 100%)
```

Godot 侧：`Environment.BG_CANVAS` + 一张按同公式（椭圆半径 = 120%宽 / 130%高，中心 32%/18%，
sRGB 逐像素）生成的贴图。实测取点差 0~2 级。

## 5. 接触阴影

页面在模型最低点铺 `CircleGeometry(r*11)` + `ShadowMaterial({opacity: 0.18})` 接主光阴影，
没有它模型会浮着。Godot 没有 shadow-only 材质，做法：

1. `SubViewport`（1024²，独立 World3D）里放一份同款 GLB，全部 `material_override` 成纯黑
   unshaded；
2. 地面放白板（albedo 1、roughness 1），一盏与主光同向的平行光开阴影，正交相机沿光看；
3. 渲 4 帧后取图：白 = 见光，黑 = 投影或被模型挡住；见光值归一化（`lit_max`）；
4. 主场景在 `bounds.position.y - 0.001` 放一张 `radius*22` 的盘，用
   `shaders/ground_shadow.gdshader` 按光空间投影采样，`ALPHA = (1-lit)*0.18`。

烘完把 SubViewport 释放，运行期不再重算。
